# Files packaged by reporting/package_and_upload.py.
#
# Every pattern below is snapshotted into run_results/<run_id>/ and uploaded as the
# full bundle. Lines tagged @core are ADDITIONALLY packaged into a second, much
# smaller "<run>_core.zip" uploaded to the same folder: the predictions and reference
# CSVs, the per-year final reports and the multiyear reports, without the rasters
# that dominate the full bundle (on the three-county Kenya study the full bundle was
# 2.8 GiB zipped, the core bundle 16 MiB).
#
# Matching is on the file's basename, so a pattern needs no path. The snapshot keeps
# each file's path relative to the study root, which is what lets the interactive
# results map read a snapshot with the same code it uses for the live outputs.
#
# The aggregation shapefiles are NOT listed here - their names vary per study, so
# package_and_upload.py copies them explicitly from the run config instead.
